# assets/

Атлас котика:

- `spritesheet.png` — один лист со всеми кадрами (4352×1024, сетка 17×4,
  ячейка 256×256, 68 кадров);
- `atlas.json` — описание сетки и анимаций;
- `preview.png` — картинка для README (четыре состояния в ряд). Нарезана
  из листа вручную и в бандл не попадает.

Лист и атлас лежат в репозитории как готовый артефакт и вшиваются в бандл
на этапе `pnpm build` (команда `pnpm sprites` перевшивает их в
`src/client/sprite-data.ts`). Скрипта нарезки спрайт-листа в проекте нет —
атлас подготовлен заранее.
