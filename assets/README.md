# assets/

Атлас котика:

- `spritesheet.png` — один лист со всеми кадрами (4352×1024, сетка 17×4,
  ячейка 256×256, 68 кадров);
- `atlas.json` — описание сетки и анимаций.

Оба файла лежат в репозитории как готовый артефакт и вшиваются в бандл на
этапе `pnpm build` (команда `pnpm sprites` перевшивает их в
`src/client/sprite-data.ts`). Скрипта нарезки спрайт-листа в проекте нет —
атлас подготовлен заранее.

Требования к листу и к формату `atlas.json` — в корневом `README.md`,
раздел «Арт».

Если атласа нет или он битый, плагин показывает встроенную canvas-заглушку —
это нормальный режим деградации, ошибкой не считается.
